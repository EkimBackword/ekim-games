# Задачи

## 1. Аутентификация и навигация

- [x] 1.1 Проверить требования `user-auth` на тестовой БД с помощью `pnpm nx run api:integration-test`. В браузере без сессии и затем с действующими cookies проверить переходы с `/`, `/login`, `/register` и неизвестного URL, а также восстановление после перезагрузки. Сверить обработку CSRF и повторного использования refresh JWT с контроллером и сервисом. Ожидаются маршруты и ответы API из спецификации.

## 2. Общий чат

- [x] 2.1 Запустить `pnpm nx run web:e2e` с Chromium и тестовой БД. Для сверки остальных сценариев использовать две активные сессии и историю из более чем 50 записей. Проверить историю, рассылку при отправке по обоим транспортам, отклонение недопустимого текста и отправки после отзыва сессии. Ожидаются последние 50 сообщений, доставка сохранённого сообщения и реакции на ошибку по `global-chat`.

## 3. PWA

- [x] 3.1 Собрать веб-клиент через `pnpm nx run web:build:production` и открыть сборку на localhost или HTTPS. Дождаться установки service worker, отключить сеть и перезагрузить страницу. Ожидаются загрузка оболочки, предупреждение и отсутствие ответов API в кэше service worker.
