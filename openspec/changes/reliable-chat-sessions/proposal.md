# Proposal

## Why

Параллельное обновление общей refresh cookie может завершить сессию во всех вкладках, а ошибка logout выглядит как успешный выход. Чат может пропустить сообщения при разрыве связи, а пользователь не может определить, сохранилась ли отправка без подтверждения.

## What Changes

- Согласовывать refresh между вкладками и показывать отдельную страницу при ошибке серверного logout.
- Привязать сокеты к `sid`, обновлять их авторизацию без переподключения и закрывать их при истечении access JWT или отзыве сессии.
- Загружать последние 50 сообщений, подгружать ранние страницы по запросу и восстанавливать пропуски, сохраняя историю и черновик открытой страницы.
- Подтверждать сохранение исходящих сообщений и сверять их с сервером после разрыва. Добавить доступные статусы и ручной повтор.
- **BREAKING** для клиентов Socket.IO: `chat:send-message` требует идентификатор попытки. REST-отправка сохраняет прежний контракт.
