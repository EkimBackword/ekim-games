# Tasks

## 1. Сессия в браузере

- [x] 1.1 Координировать восстановление и плановый refresh, а также запросы, меняющие cookies. В Playwright открыть две вкладки одного browser context с действующими cookies, пересечь восстановление и плановое обновление и задержать ответ первой вкладки. Обе вкладки должны остаться авторизованными, а второй запрос должен использовать обновлённую cookie. В интеграционном тесте повторить действительно использованный JWT и получить отказ с отзывом сессии.
- [x] 1.2 Добавить маршрут ошибки logout и различить исходы в клиенте. В Playwright вернуть успешный ответ, HTTP-ошибку и сетевой сбой при активном чате. Проверить `/login` при успехе и `/logout-error` при ошибке, очистку локальной авторизации и закрытие сокета в обоих случаях, переход по ссылке с действующей и недействующей cookie. В тесте с задержанным refresh проверить, что поздний результат не восстанавливает локальное состояние после logout.
