# Контракты

Общие Zod-схемы и выведенные из них TypeScript-типы для REST API и Socket.IO.

- Никнейм: 3–24 Unicode-буквы/цифры, `_` или `-`; регистрация уникальна без учёта регистра.
- Пароль: 12–128 символов.
- Сообщение: после trim от 1 до 2000 символов.
- Входящее имя автора не принимается: API берёт его из активной JWT-сессии.
- Данные API и Socket.IO проверяются схемами на runtime-границах.
